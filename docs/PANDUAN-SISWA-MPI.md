# Panduan Siswa — Media Interaktif (1 halaman)

**Membuka:** menu **Materi** → pilih materi bertanda **Media Interaktif** → **Mulai Belajar**. Jika ada **Tes Awal**, kerjakan
dulu (sekali saja, tidak apa-apa kalau belum tahu).

**Peta stasiun:** setiap stasiun bertanda 🔒 terkunci (alasannya ditulis), terbuka, sedang dipelajari, atau
✓ selesai dengan bintang. Stasiun **Opsional** boleh dilewati. Tekan stasiun untuk mulai; kamu bisa berhenti kapan
saja dan **melanjutkan dari langkah terakhir**.

**Mengerjakan langkah:**

1. Baca/tonton penjelasan, lalu tekan **Lanjut**.
2. Pada latihan, jawab lalu tekan **Periksa**. Salah? Baca alasannya, lalu **Coba lagi**.
3. Bingung? Buka **Petunjuk** satu per satu. Masih buntu setelah mencoba? **Tunjukkan jawaban** (bintang berkurang).
4. Di latihan Flowgorithm: susun blok, tekan **Jalankan** atau **Langkah**, lihat Console & Pantau Variabel, dan
   **Coba contoh uji** sebelum Periksa. Ada uji tersembunyi — pastikan programmu benar untuk isian lain juga.

**Bintang:** ⭐⭐⭐ tanpa salah; berkurang karena salah, petunjuk, atau tunjukkan jawaban. Bintang terbaik yang
disimpan, jadi stasiun boleh **diulang** untuk menambah bintang.

**Setelah stasiun selesai:** baca **Ringkasan**, tulis **refleksi** singkat dengan jujur, lalu ikuti saran:
**Belajar ulang** (jika masih sulit) atau **Tantangan** (jika dapat 3 bintang). Lencana masuk ke **Prestasiku**.

**Alat bantu di atas:**

| Tombol | Kegunaan |
|---|---|
| **Glosarium** | Cari arti istilah. |
| **Bacakan** | Teks dibacakan (pakai earphone di kelas). |
| **100%** (ukuran huruf) | Tekan berulang untuk memperbesar huruf. |
| **Kurangi animasi** | Matikan animasi jika HP lambat. |
| **Prestasiku** | Lencana & bintang yang sudah kamu kumpulkan. |
| **Papan Peringkat** | Peringkat kelas (jika diaktifkan guru). |
| **Lembar Ringkas** | Ringkasan semua stasiun untuk dicetak/dibaca ulang. |
| **Layar penuh** | Tampilan penuh agar lebih fokus. |

**Sinyal lemah?** Lanjutkan saja. Posisi dan refleksi disimpan di HP dan dikirim otomatis saat sinyal kembali.
Video memakai kuota — lewati jika sinyal lemah. Jawaban latihan butuh sinyal untuk diperiksa.

**Selesai semua stasiun wajib?** Kerjakan **Tes Akhir** untuk melihat kemajuanmu. Selamat belajar! 🚀
